המדריך, שלב אחרי שלב

את החלק הטכני קלוד עושה. אתם רק לוחצים על כמה כפתורים אצל מטא, GitHub ו-cron-job.org, ומאשרים.

1

פותחים אפליקציה אצל מטא

≈ 10 דק׳

האפליקציה היא "המפתח" שדרכו מותר לקלוד לפרסם בשם העמוד שלכם. היא לא מפרסמת כלום בפרופיל הפרטי.

  1. נכנסים ל-developers.facebook.com עם הפרופיל האישי שמנהל את העמוד. לא בתור העמוד עצמו, כי עמוד לא יכול להיות מפתח.
  2. Create App ← נותנים שם (למשל My Publisher) ← Next.
  3. במסך Use cases לוחצים משמאל על Content management, ומסמנים שניים: Manage messaging & content on Instagram וגם Manage everything on your Page.
  4. במסך Business בוחרים I don't want to connect a business portfolio yet. אחר כך Next עד Create app.
  5. בלוח הבקרה של האפליקציה: Customize the Manage messaging & content on Instagram ← Permissions and features. ליד instagram_basic ו-instagram_content_publish צריך להופיע Ready for testing.
העמוד שלכם לא יופיע במסך ה-Business, וזה תקין. בוחרים אותו בשלב הבא.
2

מחברים את העמוד ואת האינסטגרם

≈ 5 דק׳
  1. נכנסים ל-Graph API Explorer (בתפריט Tools) ובוחרים למעלה את האפליקציה שלכם.
  2. ב-User or Page בוחרים Get User Access Token.
  3. ב-Add a Permission מקלידים ולוחצים Enter אחרי כל אחת: pages_show_list business_management instagram_basic instagram_content_publish
  4. Generate Access Token ← בוחרים הצטרפות לדפים הקיימים בלבד ← מסמנים רק את העמוד שלכם, ובמסכים הבאים רק את העסק ואת האינסטגרם שלו.
את הקודים לא מדביקים בצ'אט. קלוד יפתח לכם קובץ keys.txt במחשב, ושם מדביקים את ה-Access Token, ואת ה-App ID וה-App Secret (מ-App settings ← Basic). הקובץ נשאר אצלכם ולא עולה לשום מקום.
3

נותנים לקלוד את הפרומפט

≈ 15 דק׳

מעתיקים את הפרומפט שלמטה ל-Claude Code, ומוסיפים איפה התוכן שלכם ובאילו שעות לפרסם. קלוד:

  • ממיר את התמונות לפורמט שמטא דורשת ומכין גרסת סטורי לכל פוסט
  • בונה לוח פרסומים ושומר אותו כקובץ שאפשר לפתוח באקסל ולבדוק
  • הופך את החיבור למטא לקבוע, כדי שלא יפוג אחרי חודשיים
  • מעלה את המערכת למאגר פרטי ב-GitHub. שם תתבקשו לאשר הרשאה אחת עם קוד חד-פעמי
  • מריץ בדיקה בלי פרסום: אינסטגרם מקבל את הפוסט, והמערכת עוצרת רגע לפני הלחיצה על "פרסם"
4

מחברים שעון חיצוני

≈ 5 דק׳

למדתי את זה בדרך הקשה: גם ל-GitHub יש תזמון מובנה, אבל במאגר חדש הוא לא הופעל אצלי בכלל, ופוסט הבוקר הראשון לא עלה. שעון חיצוני פתר את זה לגמרי.

  1. ב-GitHub: Settings ← Personal access tokens ← Fine-grained ← בוחרים רק את המאגר של המערכת, ונותנים הרשאת Actions: Read and write. המפתח הזה יכול רק להפעיל את המערכת, ושום דבר אחר.
  2. ב-cron-job.org: נרשמים ← Settings ← API ← יוצרים מפתח. את IP Address Restriction משאירים ריק.
  3. את שני המפתחות מדביקים ב-keys.txt, וקלוד מגדיר את כל השעות לבד.
5

מאשרים את הלוח, ויוצאים לדרך

שום דבר לא עולה לעמוד לפני שאתם מאשרים. עוברים על לוח הפרסומים, מבקשים שינויים (שעות, סדר, טקסטים, ימים בלי פרסום), ורק אז קלוד מפעיל.

לדוגמה, הלוח שלי:

  • 08:30 פוסט · 13:00 פוסט · 15:30 טיזר לסטורי · 17:00 ריל ניסיון (טריאל) · 20:30 ריל לעמוד
  • כל פוסט וריל שעולים לעמוד יוצאים גם לסטורי, כמה דקות אחריהם
  • שישי פוסט אחד בבוקר, ובמוצאי שבת ריל, לפי שעת צאת השבת

הפרומפט המוכן

מעתיקים אותו כמו שהוא ל-Claude Code, ובסוף משלימים את הפרטים שלכם.

פרומפט ל-Claude Code
אני רוצה שתבנה לי מערכת שמפרסמת לאינסטגרם של העסק שלי לבד, לפי לוח זמנים קבוע.

איך המערכת צריכה לעבוד:
- הפרסום עובר דרך הממשק הרשמי של מטא (Instagram Graph API, דרך Facebook Login), עם טוקן קבוע של העמוד.
- המערכת יושבת במאגר פרטי ב-GitHub ורצה ב-GitHub Actions. הקבצים מגיעים לאינסטגרם רק ברגע הפרסום, דרך קישור זמני (למשל Cloudflare quick tunnel), ולא נשמרים באתר ציבורי.
- לוח הזמנים שמור בקובץ אחד (schedule.json), וכל מה שכבר עלה נרשם בקובץ אחר (state.json), כדי שאף פוסט לא יעלה פעמיים.
- בכל הפעלה מתפרסם פריט אחד בלבד, ואם משהו נכשל, יש עד 3 ניסיונות.
- השעון שמפעיל את המערכת הוא cron-job.org (בקשת workflow_dispatch). אל תסמוך רק על התזמון של GitHub.
- תמונות הופכות ל-JPEG, ולכל פוסט נוצרת גרסת סטורי 9:16.
- כל פוסט וריל שעולים לעמוד יוצאים גם לסטורי כמה דקות אחריהם, וכל ריל עולה גם כריל ניסיון (trial_params, graduation MANUAL).
- צריך מצב בדיקה שבונה את הפוסט אצל אינסטגרם ועוצר לפני הפרסום.

כללים:
- אל תבקש ממני להדביק קודים בצ'אט. פתח לי קובץ keys.txt במחשב (שלא עולה ל-GitHub), ותקרא ממנו.
- תדריך אותי צעד אחרי צעד בכל מה שצריך ללחוץ אצל מטא, GitHub ו-cron-job.org, ותחכה עד שאגיד שסיימתי.
- לפני שמשהו עולה לעמוד, תראה לי את לוח הפרסומים המלא (קובץ שנפתח באקסל), ותפעיל רק אחרי שאאשר.
